# Coffee Website ☕

Projeto de um Website de café, utilizando React, TypeScript, Vite, Tailwind CSS, bibliotecas de animação como Framer Motion, Swiper e React Spinners, e uma API de café. Este projeto tem como intuito testar e praticar conceitos e bibliotecas do React.

## 📚 API

Nesse projeto, foi utilizado a API [Sample APIs/Coffee](https://sampleapis.com/api-list/coffee) para obter as informações sobre os cafés.

## 🛠 Tecnologias

- React;
- TypeScript;
- Tailwind CSS;
- Framer Motion;
- Swiper;
- React Spinners;
- React Spring;
- Vite;
- Sample APIs.

## 🔧 Instruções de Instalação

### Pré-requisito: instale o [Node.js](https://nodejs.org/pt-br), recomenda-se a versão LTS.

---

Para executar o projeto localmente, siga os passos abaixo.

### 1. Clone o repositório

Abra a pasta em que deseja clonar o repositório e coloque o seguinte prompt no terminal:

```bash
git clone https://github.com/DanielsSon12/coffee_website_project.git
```

### 2. Acesse a pasta do projeto

```bash
cd coffee_website_project
```

### 3. Instale as dependências

Abra o terminal no projeto e digite:

```bash
npm install
```

### 4. Execute o projeto

Abra o terminal no projeto novamente e digite:

```bash
npm run dev
```

Após executar o comando, o Vite disponibilizará o projeto localmente. Acesse o endereço exibido no terminal, normalmente:

```bash
http://localhost:5173
```
